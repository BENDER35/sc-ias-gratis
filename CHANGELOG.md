# Changelog

## v1.0.0

- Instalador interactivo (`install_ias.sh`) con 8 CLIs de IA con plan gratuito:
  opencode, Claude Code, Gemini CLI, OpenAI Codex CLI, GitHub Copilot CLI,
  Qwen Code, Ollama y Aider.
- Menú con selección múltiple, modo `--all` y resumen de instalación.
- Espejo automático bidireccional GitHub ⇄ GitLab mediante GitHub Actions y
  GitLab CI, con protección contra bucles y pérdida de historial.
- Scripts de verificación y de publicación de release con ZIP.
